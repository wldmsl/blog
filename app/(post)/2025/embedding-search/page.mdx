"리액트 훅 에러"를 검색했을 때 "React hook 오류", "use state 문제" 같은 것도 같이 나오게 하고 싶었다. 키워드 검색은 정확한 단어가 있어야 하니까 한계가 있다.

임베딩으로 의미 기반 검색 만들어봤다.

---

**기본 흐름**

1. 문서들을 임베딩으로 변환해서 저장
2. 검색어를 임베딩으로 변환
3. 저장된 벡터들과 코사인 유사도 계산
4. 유사도 높은 것 반환

---

**문서 임베딩 & 저장 (미리 해두는 것)**

```ts
import OpenAI from 'openai'

const openai = new OpenAI()

async function embedDocument(text: string) {
  const response = await openai.embeddings.create({
    model: 'text-embedding-3-small',
    input: text,
  })
  return response.data[0].embedding
}

// 문서들 미리 임베딩해서 저장
const documents = [
  { id: '1', content: 'React useState 사용법과 주의사항' },
  { id: '2', content: 'Next.js SSR 데이터 페칭 방법' },
  { id: '3', content: '타입스크립트 제네릭 이해하기' },
]

const embeddings = await Promise.all(
  documents.map(async (doc) => ({
    ...doc,
    vector: await embedDocument(doc.content),
  }))
)
```

**코사인 유사도 계산**

```ts
function cosineSimilarity(a: number[], b: number[]): number {
  const dot = a.reduce((sum, val, i) => sum + val * b[i], 0)
  const normA = Math.sqrt(a.reduce((sum, val) => sum + val * val, 0))
  const normB = Math.sqrt(b.reduce((sum, val) => sum + val * val, 0))
  return dot / (normA * normB)
}

async function search(query: string, topK = 3) {
  const queryVector = await embedDocument(query)
  
  const scored = embeddings.map((doc) => ({
    ...doc,
    score: cosineSimilarity(queryVector, doc.vector),
  }))
  
  return scored
    .sort((a, b) => b.score - a.score)
    .slice(0, topK)
}

// 테스트
const results = await search('hook 에러')
// → ['React useState 사용법과 주의사항', ...] 같은 식으로 나온다
```

**실제 사용하면서 발견한 것들**

문서가 너무 길면 임베딩 품질이 떨어진다. 긴 문서는 청크(chunk)로 나눠서 각 청크를 임베딩하는 게 낫다.

```ts
function chunkText(text: string, size = 500, overlap = 50): string[] {
  const chunks = []
  let start = 0
  
  while (start < text.length) {
    chunks.push(text.slice(start, start + size))
    start += size - overlap  // overlap으로 문맥 유지
  }
  
  return chunks
}
```

---

문서 개수가 적으면 직접 코사인 유사도 계산해도 되는데, 수천 개 넘어가면 벡터 DB를 써야 한다. 매번 전체 다 계산하면 느려진다.

pgvector 쓰면 PostgreSQL에서 바로 벡터 검색 가능하다:

```sql
SELECT content, 1 - (embedding <=> $1) AS similarity
FROM documents
ORDER BY similarity DESC
LIMIT 5;
```

`<=>` 연산자가 코사인 거리 계산해준다. 편하다.
