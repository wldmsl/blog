처음 AI API 쓸 때는 그냥 사용자 입력을 그대로 던졌는데, 결과물이 기대에 못 미쳤다.

```ts
// 처음엔 이렇게만 했다
const response = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [{ role: 'user', content: userInput }]
})
```

AI가 뭘 해야 하는지 컨텍스트가 없으니 당연한 거였다.

---

**System prompt의 역할**

```ts
const response = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [
    {
      role: 'system',
      content: `당신은 코드 리뷰 전문가입니다.
- 한국어로 답변하세요
- 구체적인 개선 방안을 제시하세요
- 버그가 있으면 반드시 지적하세요
- 코드 예시를 포함하세요`
    },
    { role: 'user', content: userInput }
  ]
})
```

system prompt로 역할, 말투, 출력 형식, 제약 조건 같은 걸 정의하면 결과물이 훨씬 일관된다.

---

**Few-shot prompting**

예시를 줬더니 형식이 훨씬 안정적으로 나왔다.

```ts
const messages = [
  { role: 'system', content: '코드를 분석해서 JSON으로 반환하세요.' },
  // 예시 1
  { role: 'user', content: 'function add(a, b) { return a + b }' },
  { role: 'assistant', content: '{"type":"function","name":"add","params":["a","b"],"complexity":"O(1)"}' },
  // 예시 2
  { role: 'user', content: 'const arr = [1,2,3].map(x => x * 2)' },
  { role: 'assistant', content: '{"type":"expression","operation":"map","complexity":"O(n)"}' },
  // 실제 질문
  { role: 'user', content: userCode }
]
```

원하는 출력 형식 예시를 conversation history처럼 넣으면 모델이 패턴을 따라간다.

---

**JSON 출력 강제**

```ts
const response = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [...],
  response_format: { type: 'json_object' },
})

const data = JSON.parse(response.choices[0].message.content)
```

`response_format`으로 JSON 강제하면 파싱 실패가 거의 없다. 전엔 "JSON으로 반환해"라고 했는데도 가끔 설명 텍스트가 섞여서 `JSON.parse`에서 터졌다.

---

**실제로 효과 있었던 것들**

- "단계적으로 생각하세요" (Chain of Thought) → 복잡한 추론 문제에서 정확도 올라간다
- 출력 예시 포함 → 형식 안정성 올라간다
- 제약 조건 명시 ("3문장 이내로") → 불필요한 말 줄어든다
- 부정형보다 긍정형 ("~하지 마세요" 대신 "~하세요") → 약간 더 잘 따르는 것 같다

---

프롬프트 짜는 것도 일종의 기술이라는 게 이해됐다. 모델마다 반응하는 방식이 다르고, 같은 프롬프트도 온도(temperature) 설정에 따라 결과가 많이 달라진다.

`temperature=0`이면 거의 결정론적으로 동작, `temperature=1`이면 창의적이지만 들쭉날쭉. 코드 생성이나 분류 문제는 낮게, 창작 작업은 높게 설정하는 게 기본인 것 같다.
