GPT처럼 글자가 하나씩 나오는 스트리밍 챗봇 만들어 봤다. 개념은 알겠는데 실제 구현이 생각보다 복잡했다.


**서버 (Route Handler)**

```ts
// app/api/chat/route.ts
import OpenAI from 'openai'

const client = new OpenAI()

export async function POST(req: Request) {
  const { messages } = await req.json()
  
  const stream = await client.chat.completions.create({
    model: 'gpt-4o',
    messages,
    stream: true,
  })
  
  const encoder = new TextEncoder()
  
  const readable = new ReadableStream({
    async start(controller) {
      for await (const chunk of stream) {
        const content = chunk.choices[0]?.delta?.content || ''
        if (content) {
          controller.enqueue(encoder.encode(content))
        }
      }
      controller.close()
    },
  })
  
  return new Response(readable, {
    headers: {
      'Content-Type': 'text/plain; charset=utf-8',
      'Transfer-Encoding': 'chunked',
    },
  })
}
```


**클라이언트**

```tsx
const [response, setResponse] = useState('')
const [isLoading, setIsLoading] = useState(false)

const sendMessage = async (userMessage: string) => {
  setIsLoading(true)
  setResponse('')
  
  const res = await fetch('/api/chat', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ messages: [{ role: 'user', content: userMessage }] }),
  })
  
  const reader = res.body?.getReader()
  const decoder = new TextDecoder()
  
  if (!reader) return
  
  while (true) {
    const { done, value } = await reader.read()
    if (done) break
    
    const text = decoder.decode(value)
    setResponse(prev => prev + text)  // 점진적으로 추가
  }
  
  setIsLoading(false)
}
```


**막혔던 것들**

처음에 `Transfer-Encoding: chunked` 헤더 빠뜨려서 스트리밍이 아니라 전체 응답 다 받고 한 번에 나왔다. 헤더가 핵심이었다.

Vercel 배포하면 기본으로 Edge Runtime이 아니라 Node.js Runtime인데, 스트리밍 제대로 하려면 설정해줘야 한다:

```ts
export const runtime = 'edge'
```

Edge Runtime에서 스트리밍이 훨씬 낫다고 한다.


**AI SDK 쓰면 훨씬 편함**

Vercel의 AI SDK(`ai` 패키지) 쓰면 이 보일러플레이트 다 필요 없다:

```ts
import { streamText } from 'ai'
import { openai } from '@ai-sdk/openai'

export async function POST(req: Request) {
  const { messages } = await req.json()
  
  const result = streamText({
    model: openai('gpt-4o'),
    messages,
  })
  
  return result.toDataStreamResponse()
}
```

클라이언트도:

```tsx
import { useChat } from 'ai/react'

const { messages, input, handleInputChange, handleSubmit } = useChat()
```

이게 훨씬 낫다. 처음부터 이거 쓸걸.
