"AI가 날씨 알려줘" 같은 기능을 만들려면 AI가 날씨 API를 직접 호출해야 하는데, 이걸 어떻게 구현하나 싶었다.

그냥 프롬프트에 "날씨 API 결과 알려줘"라고 하면 AI가 환각해서 없는 날씨 데이터를 만들어낸다.

Tool calling (Function calling)을 쓰면 됐다.

---

**개념**

1. AI에게 쓸 수 있는 도구(함수) 목록을 알려준다
2. AI가 필요하다고 판단하면 "이 함수 써줘" 하고 요청
3. 내가 그 함수 실행해서 결과 돌려준다
4. AI가 결과 받아서 최종 답변 생성

---

**구현**

```ts
import OpenAI from 'openai'

const client = new OpenAI()

// 도구 정의
const tools: OpenAI.Chat.ChatCompletionTool[] = [
  {
    type: 'function',
    function: {
      name: 'get_weather',
      description: '특정 도시의 현재 날씨를 가져옵니다',
      parameters: {
        type: 'object',
        properties: {
          city: {
            type: 'string',
            description: '날씨를 조회할 도시명 (예: Seoul, Tokyo)',
          },
          unit: {
            type: 'string',
            enum: ['celsius', 'fahrenheit'],
            description: '온도 단위',
          },
        },
        required: ['city'],
      },
    },
  },
]

// 실제 함수
async function get_weather(city: string, unit = 'celsius') {
  // 실제로는 날씨 API 호출
  return { temperature: 22, description: '맑음', city, unit }
}

// 실행 루프
async function chat(userMessage: string) {
  const messages: OpenAI.Chat.ChatCompletionMessageParam[] = [
    { role: 'user', content: userMessage },
  ]
  
  while (true) {
    const response = await client.chat.completions.create({
      model: 'gpt-4o',
      messages,
      tools,
    })
    
    const message = response.choices[0].message
    messages.push(message)
    
    // tool call 없으면 최종 답변
    if (!message.tool_calls || response.choices[0].finish_reason === 'stop') {
      return message.content
    }
    
    // tool call 있으면 함수 실행
    for (const toolCall of message.tool_calls) {
      const { name, arguments: args } = toolCall.function
      const parsedArgs = JSON.parse(args)
      
      let result
      if (name === 'get_weather') {
        result = await get_weather(parsedArgs.city, parsedArgs.unit)
      }
      
      messages.push({
        role: 'tool',
        tool_call_id: toolCall.id,
        content: JSON.stringify(result),
      })
    }
    
    // AI에게 결과 돌려주고 다시 응답 생성
  }
}

// 테스트
const answer = await chat('서울 날씨 어때?')
// → "서울의 현재 날씨는 맑음이며 기온은 22°C입니다."
```

---

**막혔던 것**

처음에 while 루프 없이 한 번만 호출했는데, AI가 tool call 요청을 반환할 때 실제 답변이 아닌 함수 호출 요청만 오고 끝났다. 함수 실행 결과를 다시 AI에게 넘겨줘야 최종 답변을 받을 수 있다.

도구 여러 개 병렬 호출도 가능하다. AI가 필요하다 싶으면 여러 함수를 동시에 호출하기도 한다.

---

이게 AI 에이전트의 핵심 개념이다. 검색, 코드 실행, DB 조회 같은 도구를 연결해주면 AI가 복잡한 작업도 처리할 수 있다. 단순 Q&A가 아니라 진짜 에이전트처럼 동작하게 만드는 거다.
